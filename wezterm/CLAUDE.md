# WezTerm Apollo Themes

## Location

This app lives at `wezterm/` in [apollo-theme/apollo-theme](https://github.com/apollo-theme/apollo-theme/tree/main/wezterm). It keeps its own exact snapshots of the root palettes in `palette/`, runs standalone from this folder with only Python's standard library, and is validated by the root CI job `wezterm`. Generated scheme metadata uses `origin_url = "https://github.com/apollo-theme/apollo-theme/tree/main/wezterm"`. **Apollo Dark** is the public name for the unsuffixed `Apollo` compatibility scheme; **Apollo Light** uses `Apollo Light` / `apollo-light`.

## Architecture

This folder publishes Apollo Dark `apollo.toml` from `palette/apollo.json` and light `apollo-light.toml` from `palette/apollo-light.json`. The existing dark scheme's filename, internal name `Apollo`, generated bytes, and activation in `wezterm.lua` remain unchanged. The additive scheme is named `Apollo Light`.

`scripts/generate.py` uses an ordered two-output map and retains pure `render(palette)` serialization. Check mode rejects missing, stale, and unexpected root-level TOML schemes. `scripts/check.py` validates both variant identities and appearances, complete WezTerm schemas, exact mappings, selection alpha, `selection_fg = "none"`, activation compatibility, and drift. Tests pin the light palette SHA-256 and verify ordered ANSI/bright slots for both variants. `tests/wezterm-check.lua` remains an isolated native-loading fixture.

Do not add font, opacity, window, or unrelated tab-bar configuration. Never write real user configuration from generation or tests.

## Install and activate

Clone the repository once to `$HOME/.config/apollo-theme` (skip if it already exists), then copy one or both TOML files from `$HOME/.config/apollo-theme/wezterm/` into the standard WezTerm colors directory; use full quoted source paths in docs. Activate Apollo Dark with `config.color_scheme = 'Apollo'`; activate Apollo Light with `config.color_scheme = 'Apollo Light'`. Existing `'Apollo'` activation must remain Apollo Dark.

## Uninstall

Activate another scheme, reload, and remove only the copied `apollo.toml` and/or `apollo-light.toml` file. Never remove the shared clone in uninstall steps. Scripts must not perform these preference changes.

## Visual check

Inspect cursor text, selected differently colored cells, and ANSI colors 0–15 for both variants. Confirm dark selection remains 50% alpha, light selection remains opaque, and both preserve cell foregrounds through `selection_fg = "none"`. Compare colors with the matching palette snapshot.

## Commands

Run from `wezterm/`:

```sh
# Build both schemes
python3 scripts/generate.py

# Missing, stale, and unexpected generated-file gate
python3 scripts/generate.py --check

# Syntax lint
python3 -m compileall -q scripts tests
luac -p wezterm.lua tests/wezterm-check.lua

# Schema, colors, both mappings, activation, and drift
python3 scripts/check.py

# Full tests
python3 -m unittest discover -s tests -v

# Named single test
python3 -m unittest tests.test_theme.WezTermThemeTests.test_native_artifact_matches_terminal_palette -v

# Native CLI validation, when WezTerm is installed (run from `wezterm/`)
wezterm --config-file tests/wezterm-check.lua show-keys >/dev/null
```
