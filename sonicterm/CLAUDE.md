# SonicTerm Apollo Themes

## Architecture

This standalone repository publishes two SonicTerm themes. `palette/apollo.json` maps deterministically to the existing dark `apollo.toml`; `palette/apollo-light.json` maps to additive `apollo-light.toml`. The existing internal name `Apollo`, filename, dark appearance, generated bytes, and activation key remain unchanged. The light theme uses internal name `Apollo Light` and `appearance = "light"`.

`scripts/generate.py` exposes an ordered two-output map while keeping `render(palette)` pure. Check mode rejects missing, stale, and unexpected root-level TOML theme artifacts. `scripts/check.py` validates both palette identities, appearances, selection semantics, exact ordered terminal mappings, tab roles, native schemas, and generated drift. `tests/test_theme.py` pins the light snapshot SHA-256 and covers both variants.

Each theme must contain top-level metadata; primary, cursor, and selection colors; two eight-color tables; and all eight tab fields. `selection_fg` remains concrete because SonicTerm requires it. Do not add window, font, opacity, or application configuration. Scripts and tests must never edit user preferences.

## Install and activate

Install one or both files in `~/.sonicterm/themes`. Activate dark Apollo with `theme = "apollo"`; activate Apollo Light with `theme = "apollo-light"`. Reload the configuration after changing the setting. Existing `theme = "apollo"` installations must remain dark.

## Uninstall

Activate another theme first, reload, then remove only the corresponding installed file (`apollo.toml` or `apollo-light.toml`). Do not mutate preferences from scripts, generators, or tests.

## Visual check

Inspect active, inactive, and hover tab states, cursor and selected text, and ordered ANSI colors 0–15 for both variants. Verify dark Apollo retains the `#141617` canvas and Apollo Light uses `#f9f5d7`; compare each result with its matching palette snapshot. SonicTerm has no standalone theme-validation CLI, so report visual validation separately.

## Commands

```sh
# Build both variants
python3 scripts/generate.py

# Missing, stale, and unexpected generated-file gate
python3 scripts/generate.py --check

# Syntax lint
python3 -m compileall -q scripts tests

# Schema, colors, both mappings, and drift
python3 scripts/check.py

# Full tests
python3 -m unittest discover -s tests -v

# Named single test
python3 -m unittest tests.test_theme.SonicTermThemeTests.test_native_artifact_matches_terminal_palette -v
```
